Vos jeux RPG Maker, jouables et éditables dans tout navigateur.

MWGP convertit les jeux créés avec RPG Maker MV, MZ, XP, VX et VX Ace en un manifeste portable (mwgp.json) accompagné de ressources décodées. Les jeux convertis se jouent hors connexion dans le navigateur, et MWGP Studio permet de les inspecter et de les éditer — cartes, événements, dialogues, base de données et ressources — sans ouvrir RPG Maker. La conversion s'effectue soit avec Node.js (la version de référence), soit directement dans votre navigateur depuis un seul fichier autoporteur : aucune installation, aucun serveur, et vos fichiers de jeu ne quittent jamais votre ordinateur.

Version Node ou version navigateur ?

Version Node (référence)Versions navigateur (autoporteuses)
Convertisseur Les commandes convert-mv, convert-rgss et convert:auto convertissent des bibliothèques entières, écrivent dans de vrais dossiers, protègent les projets édités lors des reconversions et sont couvertes par les suites de test du projet. Un seul fichier HTML convertit un jeu à la fois, entièrement sur votre machine, et produit une page jouable, un ZIP ou un dossier. Mêmes règles de conversion et mêmes limites de compatibilité que la commande.
Studio Le Studio serveur édite les dossiers convertis sur disque : sauvegardes protégées, versions des ressources, comparaison avec la dernière conversion, et validation par le validateur MWGP complet avant toute publication. Le Studio autonome édite une page de jeu autoporteuse en mémoire et télécharge une page régénérée. C'est le même éditeur graphique, sans serveur.
Lecteur Le lanceur sert votre bibliothèque en local et joue les jeux convertis dans le navigateur. Chaque page de jeu embarque son lecteur, son moteur et ses ressources ; les sauvegardes vivent dans le stockage du navigateur.

Limites des versions autoporteuses

  • Tout tient dans la mémoire du navigateur : les très gros jeux peuvent dépasser ce qu'un onglet peut contenir ; préférez alors le convertisseur Node ou la sortie en dossier.
  • L'écriture directe dans un dossier exige l'API File System Access (Chromium) ; sinon, utilisez le téléchargement ZIP. L'export ZIP suit les limites classiques (moins de 4 Gio, moins de 65 535 fichiers).
  • Les pages de jeu demandent un navigateur récent avec décompression gzip (DecompressionStream). Les sauvegardes sont conservées par jeu dans le navigateur, jamais réécrites dans le fichier HTML.
  • Le Studio autonome conserve les éditions en mémoire jusqu'au téléchargement de la page régénérée ; il ne réécrit pas dans un dossier projet, les aperçus image/audio/vidéo des ressources ne se chargent pas via son API en mémoire (les ressources texte s'éditent normalement), et son contrôle structurel intégré est plus léger que le validateur Node.
  • La SoundFont propre au jeu est embarquée quand elle existe ; la SoundFont partagée de secours est une fonction du serveur Node, sinon le MIDI utilise le synthétiseur intégré.
  • La conversion ne vérifie pas le gameplay ; les suites de test Node et le harnais navigateur restent les contrôles de référence.

Télécharger avec npm

Le paquet npm fournit la version Node : le lanceur, les convertisseurs et les commandes Studio, sur toute machine avec Node.js 18 ou plus récent. Installation globale :

npm install -g mwgp

mwgp serve                      # lanceur local et serveur Studio
mwgp convert-auto RPGM_versions MWGP_versions
mwgp studio lift MWGP_versions/MonJeu/mwgp.json studio/MonJeu

Ou sans installation, via npx :

npx mwgp convert-mv "chemin/vers/MonJeu" "MWGP_versions/MonJeu"
npx mwgp validate "MWGP_versions/MonJeu/mwgp.json"

Vous préférez les sources ? Clonez le dépôt GitHub, lancez npm install puis npm start. Les versions navigateur en un fichier ci-dessus sont générées depuis ces sources avec npm run export:converter et npm run export:studio.

Comment ça marche

Les convertisseurs lisent les données du projet d'origine (JSON MV/MZ, ou données et scripts Ruby XP/VX/Ace, archives RGSS chiffrées comprises) et écrivent un manifeste MWGP explicite : cartes avec leurs commandes d'événements converties, base de données, images et audio décodés, JavaScript des plugins du jeu et bibliothèque Ruby transpilée. Le lecteur exécute ce manifeste dans le navigateur ; les scripts d'événements font tourner le code propre au jeu dans un bac à sable, sans réimplémenter sa logique. La compatibilité est rapportée par projet, et toute forme non prise en charge produit un avertissement explicite, jamais un abandon silencieux.
