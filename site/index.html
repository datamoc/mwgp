Your RPG Maker games, playable and editable in any browser.

MWGP converts games made with RPG Maker MV, MZ, XP, VX and VX Ace into a portable manifest (mwgp.json) plus decoded resources. Converted games play offline in the browser, and the MWGP Studio lets you inspect and edit them — maps, events, dialogues, database and resources — without opening RPG Maker. Conversion runs either with Node.js (the reference version) or directly in your browser from a single self-contained file: no installation, no server, and your game files never leave your computer.

Node version or browser version?

Node version (reference)Browser versions (self-contained)
Converter convert-mv, convert-rgss and convert:auto CLIs convert whole libraries, write into real folders, protect edited projects on reconversion, and are covered by the project's test suites. One HTML file converts one game at a time, entirely on your machine, and can produce a playable page, a ZIP or a folder. Same conversion rules and compatibility limits as the CLI.
Studio The Studio server edits converted folders on disk: protected saves, asset versioning, comparison with the last conversion, and validation by the full MWGP validator before anything is published. The standalone Studio edits a self-contained game page in memory and downloads a regenerated page. It is the same graphical editor, without a server.
Player The launcher serves your library locally and plays converted games in the browser. Each playable game page carries its player, runtime and resources; saves live in the browser's storage.

Limits of the self-contained versions

  • Everything runs in browser memory: very large games may exceed what a browser tab can hold; prefer the Node converter or folder output for those.
  • Direct folder writing needs the File System Access API (Chromium); elsewhere, use the ZIP download. ZIP export follows classic ZIP limits (under 4 GiB, fewer than 65,535 files).
  • Game pages need a recent browser with gzip decompression (DecompressionStream). Saves are stored per game in the browser, not written back into the HTML file.
  • The standalone Studio keeps edits in memory until you download the regenerated game page; it does not write back into a project folder, image/audio/video resource previews by URL do not load through its in-memory API (text resources edit normally), and its built-in structural check is lighter than the Node validator.
  • A game's own SoundFont is embedded when present; the shared fallback SoundFont is a Node-server feature, so MIDI otherwise uses the built-in synth.
  • Conversion does not verify gameplay; the Node test suites and browser harness remain the reference checks.

Download with npm

The npm package gives you the Node version: the launcher, the converters and the Studio commands on any machine with Node.js 18 or newer. Install it globally:

npm install -g mwgp

mwgp serve                      # local launcher and Studio server
mwgp convert-auto RPGM_versions MWGP_versions
mwgp studio lift MWGP_versions/MyGame/mwgp.json studio/MyGame

Or use it without installing, through npx:

npx mwgp convert-mv "path/to/MyGame" "MWGP_versions/MyGame"
npx mwgp validate "MWGP_versions/MyGame/mwgp.json"

Working from the source instead? Clone the GitHub repository, run npm install then npm start. The single-file browser versions above are generated from that source with npm run export:converter and npm run export:studio.

How it works

Converters read the original project's data (MV/MZ JSON, or XP/VX/Ace data and Ruby scripts, including encrypted RGSS archives) and write an explicit MWGP manifest: maps with their converted event commands, the database, decoded images and audio, the game's own plugin JavaScript and transpiled Ruby library. The player runs that manifest in the browser; event scripts run the game's own code in a sandbox, so no game-specific logic is reimplemented. Compatibility is reported per project, and unsupported shapes are loud warnings, never silent drops.
